# Focus

A Pomodoro timer with focus and break phases, statistics, sound, and calendar export. Installs as an app on Windows, Mac, iPhone, and Android.

Live: https://cyrus1016.github.io/f0cus/

## Install
- Windows or Mac (Chrome or Edge): open the link, click the install icon in the address bar.
- iPhone (Safari): open the link, tap Share, tap Add to Home Screen.

## Files
All files sit at the top level of the repo. Do not put them in folders.

- `index.html` the app
- `manifest.webmanifest` install metadata
- `sw.js` offline cache
- `icon-180.png`, `icon-192.png`, `icon-512.png` app icons
